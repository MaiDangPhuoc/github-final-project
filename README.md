# Paradise Nursery - Houseplant Shopping Application

Paradise Nursery is an intuitive, responsive React web application designed for browsing and purchasing indoor houseplants. The project features state management powered by **Redux Toolkit**, categorical plant listings, dynamic cart tracking, and quantity adjustments.

## Features

- **Landing Page:** Welcomes users with background imagery, brand details, and an interactive "Get Started" call-to-action button.
- **Product Listing Page:** Displays houseplants categorized into three distinct groups. Users can add plants to their cart, which dynamically updates the navbar counter and disables the "Add to Cart" button for selected items.
- **Shopping Cart Page:** Real-time calculation of item subtotals, unit pricing, total item counts, and grand totals. Includes functional controls for incrementing, decrementing, and deleting items.
- **Responsive Header & Navigation:** Displays dynamic cart status across product and cart pages.

## Technologies Used

- **React** (Vite / Create React App)
- **Redux Toolkit** (Global state management)
- **CSS3** (Responsive styling & Layouts)
- **GitHub Pages** (Application deployment)
